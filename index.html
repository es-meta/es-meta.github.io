ESMeta

ECMAScript Specification Metalanguage

ESMeta extracts a mechanized specification from a given version of the JavaScript language specification (ECMA-262) and automatically generates language-based tools: a JavaScript interpreter, a double debugger, a conformance test synthesizer, and a specification type analyzer.

Try the Playground GitHub

The playground runs the ECMAScript Double Debugger in your browser, with no installation.

Used in the CI of ECMA-262 and Test262 · Bugs found by ESMeta
